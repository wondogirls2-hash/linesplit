# ParagraphSplitter Chrome Extension

Manifest V3 popup that splits a paragraph into one sentence per line **on-device**.

## Load unpacked (local)

1. Open `chrome://extensions`
2. Enable **Developer mode**
3. **Load unpacked** → select this `chrome-extension` folder
4. Pin the extension and open the popup

## Publish to Chrome Web Store

1. Zip the contents of this folder (not the parent repo)
2. Go to [Chrome Web Store Developer Dashboard](https://chrome.google.com/webstore/devconsole)
3. Pay the one-time registration fee if needed
4. Upload the zip, fill listing text/screenshots, submit for review
